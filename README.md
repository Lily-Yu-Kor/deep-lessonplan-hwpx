# deep-lessonplan-hwpx — 깊이있는 수업 지도안 HWPX 생성기

『2022 개정 교육과정 기반 수업설계 도움자료』의 '깊이있는 수업' 양식에 맞춰 **JSON → 한글(.hwpx) 지도안**을 만드는 도구입니다.
초·중학교 공통 교과의 2022 개정 교육과정(교육부 고시 제2022-33호)에서 뽑은 **핵심 아이디어·내용 요소·성취기준·해설·
적용 시 고려 사항 데이터**가 함께 들어 있어, 지도안의 교육과정 칸을 원문 문구 그대로 채울 수 있습니다.

> ⚠ 생성된 지도안은 **초안**입니다. 교육과정 데이터는 PDF에서 기계로 추출한 것이므로, 수업에 쓰기 전에 반드시
> **교사가 내용과 원문을 검토**해 주세요(특히 `needs_review` 표시 항목).

| mode | 양식 (도움자료 인쇄 쪽) | 용도 |
|---|---|---|
| `lesson` (기본) | 40쪽 「깊이있는 수업을 위한 차시별 교수·학습 지도안」 (작성 요령 41쪽) | 1차시 지도안 |
| `unit` | 38쪽 「깊이있는 단원 수업 설계안」 + 「깊이있는 수업 과정안」 (작성 요령 39쪽) | 단원·여러 차시 설계. `lessons: [...]`를 넣으면 뒤에 차시별 지도안이 새 쪽으로 붙음 |

50쪽 이후 예시(교과별)의 표기 방식을 따릅니다: 음영 표지(`탐구`/`실행`/`성찰`/`동기유발`…), `활동 1.` 색 굵은 제목,
`•`/`–` 개조식, 주안점 칸 글머리표, ■/□ 체크박스. 교사–학생 문답(대본)은 쓰지 않습니다.

## 파일 구성
| 경로 | 내용 |
|---|---|
| `render.py` | 생성기. JSON → .hwpx (Python 3 표준 라이브러리만 사용) |
| `preview.py` | .hwpx → PDF/PNG 미리보기(쪽 넘김 확인용, LibreOffice + H2Orestart + python3-uno) |
| `lookup.py` | 교육과정 데이터 조회(교과·학년군·영역·코드 → 핵심 아이디어·내용 요소·해설·고려 사항), 지도안 문구 검사 |
| `setup.sh`, `fonts-render.conf` | 미리보기 도구 설치, 미리보기용 글꼴 대체(맑은 고딕 → 나눔고딕) |
| `data/curriculum/*.json` | 교과별 교육과정 데이터(15개 파일) |
| `scripts/extract_curriculum.py`, `scripts/qa_curriculum.py` | 데이터 추출·검수 스크립트(원문 PDF는 저장소에 없음) |
| `docs/QA.md` | 데이터 검수 결과 |
| `examples/` | `초5_영어_길묻고답하기.json`(lesson 실행본), `예시_단원설계_초5영어_길안내.json`(unit 형식 예시) |
| `SKILL.md` | AI 에이전트용 작업 절차(요청 파악 → 성취기준 → 교육과정 데이터 → JSON → 검증 → 렌더 → 쪽 넘김 확인) |

## 설치
```bash
git clone https://github.com/Lily-Yu-Kor/deep-lessonplan-hwpx.git
cd deep-lessonplan-hwpx
python3 render.py --help          # 생성기·조회 도구는 Python 3.8+ 만 있으면 바로 동작
bash setup.sh                     # (선택) 미리보기용: LibreOffice, Java, python3-uno, lxml, H2Orestart 0.7.14 내려받아 설치
```
- `setup.sh`는 Debian/Ubuntu(apt, sudo) 기준입니다. H2Orestart 확장(.oxt)은 저장소에 넣지 않고 GitHub 릴리스에서
  `vendor/`로 내려받습니다.
- 미리보기에는 나눔고딕 글꼴(`fonts-nanum`)이 있으면 좋습니다.

## 빠른 실행
```bash
python3 render.py examples/초5_영어_길묻고답하기.json -o out/초5_영어.hwpx --allowed-codes 6영02-05
python3 preview.py out/초5_영어.hwpx -o out/preview      # PDF + 쪽별 PNG
python3 render.py input.json --dump-text                 # 검증용 본문 텍스트
```
옵션: `--allowed-codes`(교사가 고른 성취기준 코드만 허용), `--strict`(`[확인 필요]`가 남으면 실패),
`--check-only`(검증만), `--allow-dialog`(문답 검사 끄기, 비권장). 종료 코드 2 = 검증 오류(파일 생성 안 함), 경고는 stderr `WARN:`.

## 요청 형식 (AI 에이전트·스킬로 쓸 때)
| 구분 | 항목 | 예 / 기본값 |
|---|---|---|

| 선택 | 수업 유형 | 질문 중심, 프로젝트, 토의·토론, 협동 등 |
| 선택 | 중점 영역·활동 | 말하기, 실험, 모둠 활동 등 |

| 선택 | 평가 방식 | 관찰 체크리스트, 자기·동료 평가 등 |
| 선택 | 삶의 맥락 | 학생 생활과 연결할 상황 |

예: **"초5 영어 길 묻고 답하기, 6차시 중 3차시, 말하기, 질문 중심, 40분"**
자세한 절차는 [`SKILL.md`](SKILL.md)를 보세요.

## 교육과정 데이터 조회 (`lookup.py`)
```bash
python3 lookup.py --list                                  # 교과·학년군·영역 목록
python3 lookup.py --code 6영02-05                         # 코드 → 교과·학년군·영역 자동 판정 + 내용 요소·해설·고려 사항
python3 lookup.py -s 영어 -g 초5 -d 표현                  # 학년은 초5 / 5학년 / 초5~6 / 중2 등으로 입력
python3 lookup.py -s 수학 -g 중2 --search 일차함수         # 키워드 검색
python3 lookup.py --annex Where                           # 영어 [별표 2] 의사소통 기능·예시문 검색
python3 lookup.py --code 6영02-05 --render > ce.json      # render.py 입력 조각(coreIdeas/contentElements/standards/sources)
python3 lookup.py --verify input.json                     # 지도안의 핵심 아이디어·내용 요소가 원문 문구 그대로인지 검사
python3 lookup.py --code 6영02-05 --json                  # 전체 결과 JSON
```
- 출력의 `[p23]`은 원문 **PDF 파일의 쪽 번호**입니다(인쇄 쪽 번호와 다름). `⚠`는 `needs_review` 항목입니다.
- 교과 별칭: 실과/기술가정/기술·가정 → `실과(기술·가정)`, 바른생활 → `바른 생활` 등.
- 과학·사회·역사는 성취기준이 영역이 아니라 학년군별 **단원**으로 묶여 있어, 코드로 조회하면 영역을 글자 겹침으로
  **추정**하고 후보 3개를 보여 줍니다. 맞는 영역은 `--domain`으로 지정하세요.
- 데이터에 없는 교과·학년(고등학교 선택 과목, 한문, 제2외국어)은 지도안에 `[확인 필요]`로 남깁니다.

### 데이터 구조 (`data/curriculum/<교과>.json`)
```jsonc
{
  "subject": "영어", "curriculum": "2022 개정 교육과정 (교육부 고시 제2022-33호)",
  "book": "[별책 14] 영어과 교육과정", "source_file": "[별책14] 영어과 교육과정.pdf",
  "pdf_pages": {"course": [11, 30], "content_system": [13, 16], "standards": [16, 30]},
  "domains": [{
    "no": 2, "name": "표현",
    "core_ideas": [{"text": "…", "source": {"file": "…pdf", "pdf_page": 14}}],
    "content_elements": {                       // 학년군: 초1~2, 초3~4, 초5~6, 중1~3
      "초5~6": {"지식·이해": [{"text": "…", "sub": "언어", "source": {…}}],
                "과정·기능": [...], "가치·태도": [...]}
    }
  }],
  "standard_blocks": [{
    "grade_heading": "초등학교 5~6학년", "domain_no": 2, "domain": "표현",
    "heading_kind": "영역",                     // 영역 | 단원(과학·사회·역사)
    "standards": [{"code": "6영02-05", "text": "…", "grade_band": "초5~6", "source": {…},
                   "explanation": [{"text": "[6영02-05] …", "source": {…}}]}],
    "explanations": [...],                      // (가) 성취기준 해설
    "considerations": [...],                    // (나) 성취기준 적용 시 고려 사항
    "extras": {"탐구 활동": [...]}              // 과학 등
  }],
  "annex2_communicative_functions": {...}       // 영어만: [별표 2] 의사소통 기능 105개와 예시문
}
```
- 모든 항목에 `source.file`(원문 파일명)과 `source.pdf_page`(쪽을 넘긴 항목은 `pdf_page_end`)가 있습니다.
- 줄바꿈으로 끊긴 문장은 이어 붙였고, 띄어쓰기 복원 근거가 부족하거나 쪽을 넘겨 이어 붙인 항목, 수식·기호가 빠졌을
  수 있는 항목 등은 `"needs_review": true`와 `review_reason`을 붙였습니다.
- 셀이 여러 학년군에 걸친 내용 요소는 각 학년군에 같은 항목을 넣고 `span`에 걸친 학년군을 적었습니다.

```bash
python3 scripts/qa_curriculum.py --pdf-dir <PDF 폴더> --img-out /tmp/qa            # 원문 글자 대조 + 무작위 표본 쪽 이미지
```

## 내용 정책 (지어내지 않기)
1. **성취기준**: cu2022 커넥터 또는 `lookup.py` 결과의 code·text를 그대로. `--allowed-codes`로 교사가 고른 목록만 허용하며,
   본문 어디에든 목록 밖 코드가 있으면 오류.
2. **핵심 아이디어·내용 요소**: 로컬 데이터(`lookup.py`)에서 해당 학년군·영역 문구를 그대로 가져오고 `lookup.py --verify`로
   검사합니다. 데이터에 없을 때만 `"[확인 필요]"`(비워 두어도 자동으로 빨간 `[확인 필요]`와 경고). 본 차시에 맞춘 구체 표현은
   원문 항목의 하위 줄로 분명히 구분합니다.
3. **문답 금지**: `교사:`, `학생:`, `T:`, `S:` 형태의 대화 스크립트는 오류. 활동은 `~하기` 개조식으로.
4. 학생 실명 등 개인정보를 넣지 않습니다.
5. **영역**: 교육과정 영역명을 씁니다(`lookup.py --list`). cu2022의 `domain` 값은 교과에 따라 틀린 경우가 있습니다(영어가 '감상'으로 나옴).

## 입력 JSON 스키마
공통: 문자열 목록 항목은 `"문자열"` 또는 `{"text": "...", "sub": ["하위 항목", ...]}` (하위는 `–`로 표시).
`"- 문장"`으로 시작하는 문자열도 한 단계 들여쓴 하위 항목이 된다. `**굵게**` 지원.

### mode = "lesson" (차시별 교수·학습 지도안)
```jsonc
{
  "mode": "lesson",
  "title": "깊이있는 수업을 위한 차시별 교수·학습 지도안",   // 선택
  "style": {                       // 모두 선택
    "theme": "teal",               // teal(빈 양식 청록) | purple(영어 예시 보라) | mono(흑백)
    "font": "맑은 고딕", "bodyPt": 10, "lineSpacing": 145,
    "autoFit": true,               // 마지막 쪽이 30% 미만으로 넘치면 줄 간격/글자 크기를 단계적으로 줄여 한 쪽 줄임
    "maxRowFraction": 0.42         // 과정 표 한 행 최대 높이(쪽 높이 비율). 넘으면 항목 경계에서 행을 나눔
  },
  "meta": {
    "subject": "영어",             // ❶과목
    "topic": "학습 주제",           // ❶학습 주제
    "domain": "표현",              // 영역
    "period": {"current": 2, "total": 6},   // 차시 n/m (모르면 null → 빈칸)
    "grade": "초등학교 5학년", "durationMin": 40   // 양식에 칸은 없음(참고용)
  },
  "coreIdeas": ["핵심 아이디어 문장", "..."],                 // 해당 부분만
  "contentElements": {                                       // ❷내용 요소(해당 차시 관련만)
    "knowledge": [...], "skills": [...], "values": [...]     // 지식·이해 / 과정·기능 / 가치·태도
  },
  "standards": [{"code": "6영02-05", "text": "…"}],          // cu2022·lookup.py 결과 그대로
  "methods": {                                               // ❸교수·학습 방법 ■/□
    "checked": ["협동학습", "탐구학습"],                      // 협동학습, 탐구학습, 문제중심학습, 토의·토론학습,
                                                             // 프로젝트 학습, 거꾸로 학습, 블렌디드 러닝
```

## 표 쪽 넘김 처리
- 모든 표: `pageBreak="CELL"`(한글 ‘쪽 경계에서 셀 단위로 나눔’), 과정 표·과정안: `repeatHeader="1"` + 제목행
  셀 `header="1"`(다음 쪽에 제목행 반복).
- 지도안을 정보 표 / 과정 표로 나누고, 과정 표는 **활동 블록마다 한 행**(같은 단계의 블록은 점선 구분,
  단계 칸은 세로 병합). 한 블록이 쪽 높이의 42%를 넘으면 항목 경계에서 행을 자동 분할.
- 높이 추정으로 과정 표의 제목행+첫 단계(도입)가 현재 쪽에 다 안 들어가면 과정 표 앞에서 쪽을 넘김.
- 셀 높이는 최소값만 저장(한글이 내용에 맞춰 늘림) → 추정 오차로 빈 공간이 생기지 않음.
- 활동 제목·음영 표지는 ‘다음 문단과 함께’(keepWithNext).

## 미리보기(preview.py) 정확도와 한계
- H2Orestart 0.7.14는 hwpx의 `pageBreak`·`repeatHeader`·셀 여백을 무시하고 행 높이를 저장값으로 고정하며 탭 채움을 '-'로
  그립니다(소스 확인). `preview.py`는 hwpx 원본 속성을 읽어 LibreOffice 표에 다시 적용(셀 단위 나눔, 제목행 반복, 자동 높이,
  셀 여백, 탭 채움 없음, 한글식 % 줄 간격)한 뒤 PDF/PNG로 내보냅니다.
- 글꼴은 맑은 고딕 대신 나눔고딕으로 그리므로 **실제 한글(한컴오피스) 화면과 줄바꿈·쪽 경계가 조금 다를 수 있습니다.**
